# Ajout du fichier `favoris_kubernetes_documentation.html` dans votre navigateur

Ce fichier contient une liste de liens vers la documentation Kubernetes, prêts à être importés dans votre navigateur comme favoris (bookmarks).

---

### 1. Importer dans Google Chrome / Brave 

- **Ouvrir le gestionnaire de favoris** :
   - Chrome : `Ctrl + Shift + O` (Windows) ou `Cmd + Option + B` (Mac)
   - Edge : `Ctrl + Shift + O` (Windows) ou `Cmd + Option + B` (Mac)

- **Cliquer sur** `⋮` (menu à trois points) → **Importer les favoris**.

- Choisir **"Fichier HTML"** comme source d’importation.

- Sélectionner le fichier `favoris_kubernetes_documentation.html`.

- Les favoris apparaîtront dans un nouveau dossier (souvent nommé “Importé” ou “Imported”).

---

### 2. Importer dans Mozilla Firefox

- **Ouvrir la bibliothèque de favoris** :
   - Menu `≡` → **Marque-pages** → **Gérer les marque-pages**.
   - Ou raccourci : `Ctrl + Shift + O` (Windows) ou `Cmd + Shift + O` (Mac).

- Dans la fenêtre **Bibliothèque**, cliquer sur **Importer et sauvegarder**.

- Choisir **Importer des signets depuis un fichier HTML**.

- Sélectionner le fichier `favoris_kubernetes_documentation.html`.

---

### 3. Vérification

- Ouvrez vos favoris / marque-pages.
- Recherchez le dossier importé et cliquez sur un lien pour tester.
- Les pages de documentation Kubernetes devraient s’ouvrir correctement.
